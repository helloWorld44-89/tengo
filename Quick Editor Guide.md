# Quick Editor Keyboard Shortcuts Guide

## Navigation
- Arrow keys: Move cursor
- Ctrl + Arrow keys: Move and select
- Alt + Arrow keys: Fast navigation

## Editing
- Tab: Insert 4 spaces
- Enter: New line
- Backspace: Delete character/selection

## File
- Ctrl+S: Save file
- Ctrl+Q or Esc: Quit editor

## Indentation
- Ctrl+[: Remove line tab
- Ctrl+]: Add line tab

## Clipboard
- Ctrl+C: Copy selection
- Ctrl+X: Cut selection
- Ctrl+V: Paste

## Undo/Redo
- Ctrl+Z: Undo
- Ctrl+Y: Redo

## Search & Selection
- Ctrl+F: Find/search
- Ctrl+A: Select all

## Advanced Editing
- Ctrl+D: Duplicate line
- Ctrl+/: Toggle comment
- Shift+Enter: Insert line below
- Ctrl+Shift+Enter: Insert line above

## Help
- Ctrl+H: Show help
